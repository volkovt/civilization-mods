# Retratos dos Heróis Sayajin

As imagens `*_source.png` são as fontes mestres quadradas dos retratos. Os arquivos DDS derivados em `ART/` são os atlases consumidos pelo Civilization V nos tamanhos 256, 128, 80, 64, 45 e 32 pixels.

Cada atlas contém um único ícone (`IconsPerRow = 1`, `IconsPerColumn = 1`). Preserve o enquadramento central e a área segura circular ao substituir uma fonte.
